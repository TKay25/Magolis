1. Purpose

This document formally requests the minimum necessary access permissions for the Magolis Unified Social Media Messaging System to operate against the organisation's Facebook Page, Instagram Business account, and WhatsApp Business number. The system consolidates inbound and outbound customer communications across all three platforms into a single, auditable dashboard. This request is submitted to obtain written authorisation from the relevant IT and business stakeholders prior to any integration being activated.

3. Scope of Access — Per Platform
f
Facebook — Page Messaging Integration

The system connects to the organisation's existing Facebook Page via the Meta Graph API (Webhooks). The designated company workstation is already logged in to the Facebook account that owns the Page — no additional login is required from the developer.

Permission / Token What It Allows Status
pages_messaging Send and receive messages on behalf of the Facebook Page Required
pages_read_engagement Read Page posts and engagement data for the inbox feed Required
Page Access Token Long-lived token scoped to the Page only (not the personal account) Required
Webhook Subscription Real-time push of incoming messages to the Magolis server endpoint Required
pages_manage_metadata Subscribe to webhook fields on the Page Required
Personal Facebook Account Access Not required — system does not access personal accounts Not Requested
Page Admin / Editor Role Not required — developer does not need admin rights to the Page Not Requested
How the token is obtained A staff member with existing Page access (on the designated workstation) generates the Page Access Token via Meta's Graph API Explorer or the Magolis setup screen. The developer never handles the Facebook login credentials directly.
▪
Instagram — Business Account Messaging

Instagram Business messaging is delivered through the same Meta Graph API as Facebook. The Instagram Business account must be linked to the organisation's Facebook Page. No separate Instagram login is required.

Permission / Token What It Allows Status
instagram_basic Read basic profile information and confirm account linkage to Page Required
instagram_manage_messages Read and send direct messages via the Instagram Business inbox Required
Webhook — instagram field Real-time push of incoming Instagram DMs to the Magolis server Required
Instagram Personal Account Access Not applicable — only Business accounts are supported Not Requested
Instagram Admin / Password Not required — access is via Page Access Token (see Facebook above) Not Requested
Pre-requisite (action by company) The organisation's Instagram Business account must be connected to the Facebook Page via Facebook Page Settings → Instagram before integration can be activated. This is a one-time step performed by a staff member — not the developer.
►
WhatsApp — Business API

WhatsApp integration uses the official WhatsApp Business Cloud API (Meta), which requires a registered WhatsApp Business number linked to a Meta Business Manager account. The developer requires only the API credentials — not access to the WhatsApp application itself.

Credential / Permission What It Allows Status
WhatsApp Business Phone Number ID Identifies the registered business number to send/receive messages from Required
WhatsApp Access Token Authenticates API calls to send messages and receive webhook payloads Required
Webhook — messages field Real-time delivery of inbound WhatsApp messages to the Magolis server Required
whatsapp_business_messaging Send template and free-form messages via the Cloud API Required
WhatsApp App Login / Password Not required — API-based integration only Not Requested
WhatsApp Business Manager Admin Not required from the developer — setup performed by authorised staff Not Requested
Note on WhatsApp Business Account registration If the organisation does not yet have a WhatsApp Business Cloud API account, one must be created and verified through Meta Business Manager by a company representative before the Magolis integration can be configured. The developer will provide technical guidance but cannot complete account registration on behalf of the company.
4. What the Developer Will NOT Access
  • Personal Facebook, Instagram, or WhatsApp accounts belonging to any staff member
  • Admin or ownership roles on the Facebook Page, Instagram account, or WhatsApp Business account
  • Facebook Business Manager settings, billing, or ad accounts
  • Company login credentials (username/password) for any social media platform
  • The ability to post content, run ads, or make structural changes to any Page or account
  • Any data beyond messages directed to the organisation's Page/business number
5. Data Handling & Security
API Tokens Storage Stored as encrypted environment variables on the server — never hard-coded or exposed in source code Message Data Stored in a PostgreSQL database (Render.com) accessible only to the system; not shared with third parties Webhook Verification All webhook payloads from Meta are verified using a shared secret token before processing Token Rotation Access tokens can be revoked and rotated at any time by the company's Facebook Page admin without developer involvement Access Revocation The company retains full ability to revoke system access at any time via Meta Business Manager or the Facebook Page settings
6. Actions Required from the Company
  • Facebook: Generate a long-lived Page Access Token for the designated Page on the company workstation and provide it to the developer for system configuration
  • Facebook: Configure the Webhook URL (https://magolis.onrender.com/webhook) and Verify Token in the Meta App Dashboard
  • Instagram: Confirm that the Instagram Business account is linked to the Facebook Page (Page Settings → Instagram)
  • WhatsApp: Provide the WhatsApp Business Phone Number ID and Access Token (obtained from Meta Business Manager)
  • WhatsApp: Register the Webhook URL in the WhatsApp product settings within Meta App Dashboard
  • Designate an internal point of contact responsible for token management and platform-level decisions
