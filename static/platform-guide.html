Section 2 — Facebook Messenger

📘 The 24-Hour Messaging Window

Facebook enforces a strict messaging policy on the Messenger API. A contact must have messaged your Page within the last 24 hours for a standard reply to work. Outside that window, you need Meta App Review approval to use MESSAGE_TAG.

Scenario Result Messaging Type Notes
Contact messaged your Page within 24 hours Works RESPONSE No special permissions needed
Contact messaged >24h ago — app not reviewed Blocked MESSAGE_TAG Error code 10 — no workaround
Contact messaged >24h ago — app approved with pages_messaging_subscriptions Works MESSAGE_TAG Tag: CONFIRMED_EVENT_UPDATE
Magolis tries CONFIRMED_EVENT_UPDATE, falls back to ACCOUNT_UPDATE, then POST_PURCHASE_UPDATE Auto-retry MESSAGE_TAG 4-attempt fallback chain built into Magolis

How to unlock bulk messaging permanently Meta App Review

1
Go to developers.facebook.com → your app → App Review → Permissions and Features.
2
Find pages_messaging_subscriptions and click Request.
3
Provide a screen recording of your broadcast flow, a privacy policy URL, and a description of your use case.
4
Once approved, Magolis automatically uses MESSAGE_TAG with CONFIRMED_EVENT_UPDATE — broadcasts reach all opted-in contacts at any time.
💡
Quick workaround while waiting for approval: Ask your contacts to send any message to your Facebook Page (e.g. "Hi"), then run your broadcast within 24 hours. Their message opens the window and RESPONSE type works immediately.

Section 3 — WhatsApp Business

💬 WhatsApp Cloud API

WhatsApp Business Cloud API is the most capable bulk messaging channel. Messages go directly to recipients' WhatsApp numbers. No 24-hour window restriction applies — but outside an active conversation, you must use a pre-approved template.

Message Type When to Use Result
Free-form message Contact messaged you within the last 24 hours Works — any content
Template message First contact, or outside 24h window Needs approved template
Broadcast to list Bulk send to opted-in numbers Supported via Cloud API

WhatsApp Business setup in Magolis Cloud API

1
Go to developers.facebook.com → create an app → add WhatsApp product.
2
Under WhatsApp → API Setup, get your Access Token and Phone Number ID.
3
Set up your webhook URL: https://magolis.onrender.com/webhook/whatsapp. Verify token: set WHATSAPP_VERIFY_TOKEN env var.
4
In WhatsApp → Message Templates, create and submit templates for approval (used for first contact or outside 24h window).
5
Set WHATSAPP_ACCESS_TOKEN, WHATSAPP_PHONE_ID, and WHATSAPP_VERIFY_TOKEN in Render environment variables.
📱
Contacts appear automatically: When someone sends a message to your WhatsApp Business number, the webhook saves them as a contact in Magolis — no manual entry needed.

Section 4 — Instagram

📸 Instagram Messaging API

Instagram DMs are accessible via the Facebook Graph API using your Page token — but your Instagram account must be a Business or Creator account linked to a Facebook Page. Without that link, the API returns error code 100.

ℹ️
Error code 100 — "nonexisting field" means your Instagram account is not linked to your Facebook Page. Go to Instagram Settings → Account → Linked Accounts and connect your Facebook Page. Magolis uses a 4-method fallback to find the Business ID but all methods require this link.
Requirement Status check
Instagram Business or Creator account Required — Personal accounts cannot use the API
Account linked to a Facebook Page Required — Without this, all API calls return error 100
FACEBOOK_PAGE_TOKEN with instagram_manage_messages Required permission on the token
Contact must have messaged first Instagram DM API only allows replies to inbound messages

Section 5 — LinkedIn

💼 LinkedIn API

LinkedIn's public API does not expose a DM or messaging endpoint. The Messaging API exists but is only available to approved CRM partners (HubSpot, Salesforce, etc.) — not to developers generally. The Conversions API is a tracking-only tool that sends event data back to LinkedIn for ad measurement; it cannot send any message to users.

LinkedIn API Purpose Can send messages?
UGC Posts API (/v2/ugcPosts) Publish posts to your LinkedIn feed Feed post (public)
Messaging API Send DMs to connections Partner access only
Conversions API Send conversion event data to LinkedIn for ad attribution No — tracking only
Sponsored Messaging Paid DM-style ads via Campaign Manager Paid ads — not an API
InMail Outreach to non-connections Manual only, credit-based

LinkedIn setup in Magolis UGC Posts API

1
Go to linkedin.com/developers/apps → create an app → associate it with a LinkedIn Company Page.
2
Under Products, request access to Share on LinkedIn (grants w_member_social) and Sign In with LinkedIn (grants r_liteprofile).
3
Generate an OAuth 2.0 access token via the OAuth 2.0 token generator in the developer portal. Copy the token.
4
Set LINKEDIN_ACCESS_TOKEN in Render environment variables. Magolis will verify and display your LinkedIn profile name on connect.
💡
Contacts: LinkedIn contacts must be added to Magolis manually or via CSV import (set platform = linkedin). There is no public API to retrieve your connections or followers as a contact list.

Section 6 — Twitter / X

𝕏 Twitter / X API

The Twitter API v2 supports DMs and tweets through Tweepy, but access is gated behind paid tiers since 2023. The free tier is read-only — no DMs, no posting. Bulk DMs require Elevated access which starts at $100/month (Basic tier) with strict rate limits.

Twitter API Tier Cost Post tweets Send DMs DM limit
Free $0/month No No Read-only
Basic $100/month Yes Limited ~1,000 DMs/day
Pro $5,000/month Yes Yes Higher limits
⚠️
DM restriction: Even on paid tiers, you can only send DMs to users who follow you or have open DMs enabled in their privacy settings. You cannot cold-DM arbitrary users even with a paid API key.

Twitter setup in Magolis API v2

1
Go to developer.twitter.com → create a project and app. Upgrade to Basic tier ($100/month) if you need to send DMs or post tweets.
2
Under Keys and Tokens, generate: Bearer Token, API Key, API Secret, Access Token, Access Secret.
3
Set all five in Render: TWITTER_BEARER_TOKEN, TWITTER_API_KEY, TWITTER_API_SECRET, TWITTER_ACCESS_TOKEN, TWITTER_ACCESS_SECRET.
4
Magolis verifies the connection by calling GET /2/users/me and displays your Twitter username in the platform status panel.
💡
Twitter "broadcast" in Magolis = posting a tweet to your timeline (reaches all followers). Individual DMs only work if the recipient follows you and the API tier allows it. Contacts must be added manually/CSV.
