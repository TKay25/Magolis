Facebook Messenger

The 24-hour messaging window is the main restriction. A contact must have messaged your Page within the last 24 hours for a standard reply. Outside that window you need Meta App Review approval.

ScenarioResultType
Contact messaged within 24hWorksRESPONSE
Outside 24h — app not reviewedBlockedError code 10
Outside 24h — app approvedWorksMESSAGE_TAG
Magolis 4-tag fallback chainAuto-retryMESSAGE_TAG
Unlocking bulk messaging

Bulk messaging outside the 24-hour window requires Meta App Review approval for the pages_messaging_subscriptions permission. Once granted, Magolis handles the messaging logic automatically — no changes needed on your end. Contact your system administrator to initiate the review process.

Quick workaround: Ask contacts to send any message to your Page first, then broadcast within 24 hours. No special permissions needed.
Instagram

Instagram DMs use the Facebook Graph API with your Page token. Your Instagram account must be a Business or Creator account linked to a Facebook Page. Without that link the API returns error 100.

Error code 100 — "nonexisting field" means your Instagram is not linked to your Facebook Page. Go to Instagram Settings → Account → Linked Accounts and connect the Page.

WhatsApp Business

The most capable bulk channel. Messages go directly to phone numbers. To initiate contact you must use a Meta-approved template. Once the contact replies, free-form messages work for 24 hours.

WhatsApp Business is pre-configured in this system. The required credentials (Access Token, Phone Number ID, and webhook verification token) are managed by the system administrator via environment variables. Contact your admin to update or rotate credentials.

📱 Auto-contacts: When someone messages your WhatsApp Business number, the webhook saves them automatically — no manual entry needed.
LinkedIn

LinkedIn's public API has no DM endpoint. The Messaging API is only available to approved CRM partners. The Conversions API is a tracking-only tool — it cannot send messages. Magolis broadcasts = posting to your feed.

LinkedIn APIPurposeSends messages?
UGC Posts (/v2/ugcPosts)Post to LinkedIn feedFeed post only
Messaging APISend DMsPartner access only
Conversions APIAd attribution trackingNo — tracking only
Sponsored MessagingPaid DM-style adsPaid ads, not API

LinkedIn integration requires an OAuth 2.0 access token with the appropriate posting permissions. Credentials are managed via environment variables by the system administrator. Broadcasts via LinkedIn publish a post to your organisation's feed — direct messaging is not available through the public API.

Contacts: LinkedIn contacts must be added manually or via CSV import (set platform = linkedin). There is no public API to retrieve connections.
Twitter / X

Twitter API v2 supports DMs and tweets via Tweepy, but access is gated behind paid tiers since 2023. Free tier is read-only. Bulk DMs require Basic tier ($100/month) with strict rate limits.

TierCostPost tweetsSend DMsDM limit
Free$0/moNoNoRead-only
Basic$100/moYesLimited~1,000/day
Pro$5,000/moYesYesHigher
DM restriction: Even on paid tiers, you can only DM users who follow you or have open DMs enabled. You cannot cold-DM arbitrary users.

Twitter / X credentials are managed by the system administrator. Five tokens are required for full functionality (Bearer Token, API Key, API Secret, Access Token, Access Secret). The appropriate API tier must be active on the developer account. Contact your admin to verify or update the connection.

Twitter "broadcast" in Magolis = posting a tweet to your timeline. Individual DMs only work if the recipient follows you and your tier allows it.
